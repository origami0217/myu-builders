ポーズ編

大項目 → 中項目 → 小項目・ポーズは1つだけ

①大項目 → ②中項目 → ③小項目（末端）の順に選ぶとポーズが確定するよ。ポーズは1つだけ（選び直すと切り替わる）。紛らわしいポーズには「固定のコツ」が自動で完成プロンプトに付くから、しゃがみ方みたいな誤解が起きにくくなる。

1大項目を選ぶ系統で絞る
2中項目を選ぶ
3小項目を選ぶ（これで確定）棒人間で形を確認してね
ポーズ未選択 — 大項目から順に選んでね。例：しゃがむ・膝をつく ＞ 深くしゃがむ ＞ 膝を抱えてしゃがむ

視線編

目の向き・全10種

顔アップの模式図＋矢印が視線の向き。表情のニュアンスがガラッと変わる最後のひと押し。

組み合わせ例：軸は重ねて指定できる

「高さ・角度」＋「距離」＋「傾け／特殊」は、同時に指定してOK。むしろ重ねた方が、狙った構図にピンポイントで届く。
